# Tiancode 1.0.3

Esta versión hace que actualizar desde GitHub conserve siempre tus datos, aunque Tiancode se instalara antes con otra edición.

- **Tus datos vuelven a aparecer:** si una actualización anterior abrió Tiancode vacío (sin sesiones, claves ni ajustes), 1.0.3 vuelve a usar la carpeta donde estaban, `%APPDATA%\ai.tiancode.desktop`. Si después de esa actualización ya introdujiste tus claves en la carpeta nueva, Tiancode la respeta y un aviso te indica dónde están tus sesiones anteriores. No se borra ni se mueve nada: la carpeta `ai.tiancode.desktop.release` se queda como estaba.
- **Tú eliges la carpeta:** en **Ajustes › General › Datos** ves qué carpeta de datos se está usando y puedes abrirla. Si la otra carpeta también tiene sesiones o claves, un botón cambia a ella y reinicia Tiancode; puedes volver cuando quieras. Un aviso te lo indica una sola vez.
- **Actualizaciones sin sorpresas:** cuando el instalador de GitHub sustituye una instalación anterior, sigue usando sus datos y guarda la elección. Una instalación en un equipo sin Tiancode empieza limpia, como siempre.
- **Más protección:**
  - Las rutas de datos heredadas del proceso que lanzó la actualización se descartan, para no mezclar carpetas.
  - Una clave de cifrado que no se puede leer nunca se sobrescribe; si no se puede descifrar, se guarda aparte.
  - Los inicios de sesión MCP cifrados con otra clave se conservan al guardar los demás.
- **Pruebas del servidor:** la prueba del cliente de plugins tiene su propio plazo y la de actualización de configuración comprueba `tiancode.json`.

La actualización conserva claves, sesiones, ajustes, respaldos y autenticación MCP. Descarga **Tiancode.exe** para instalar o **Tiancode-portable.exe** para la edición portátil. La versión portátil guarda sus datos junto al ejecutable y no cambia.
