# Tiancode Web 1.0.6

Sitio oficial de Tiancode 1.0.6, publicado en https://tiancode.vercel.app/.

- **Novedades 1.0.6:** Inteligencia funciona de verdad y suma decisiones locales sin conexión; Uso de la PC, Notificaciones y General se rediseñan; el CLI queda a la altura del de opencode. La entrada de 1.0.5 pasa a «Anterior».
- **Portada y descargas:** versión y enlaces de descarga actualizados (SIZE_LABEL); el texto de portada y la sección de novedades describen esta versión en español e inglés.
- **Caché:** hojas de estilo y scripts con el sufijo `?v=1.0.6-r1` para que el navegador cargue la versión nueva.

Descargas de la aplicación: https://github.com/Dreftian/Tiancode/releases/tag/v1.0.6

El archivo adjunto contiene el sitio estático completo (HTML, CSS, JS e imágenes) tal y como se despliega.
