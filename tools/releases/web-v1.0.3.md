# Tiancode Web 1.0.3

Sitio oficial de Tiancode 1.0.3, publicado en https://tiancode.vercel.app/.

- **Novedades 1.0.3:** actualizar desde GitHub conserva siempre tus sesiones, claves y ajustes, y Ajustes › General › Datos permite elegir la carpeta de datos. La entrada de 1.0.2 pasa a «Anterior».
- **Portada y descargas:** versión y enlaces de descarga actualizados (~343 MB); el texto de portada y la sección de novedades describen esta versión en español e inglés.
- **Caché:** hojas de estilo y scripts con el sufijo `?v=1.0.3-r1` para que el navegador cargue la versión nueva.

Descargas de la aplicación: https://github.com/Dreftian/Tiancode/releases/tag/v1.0.3

El archivo adjunto contiene el sitio estático completo (HTML, CSS, JS e imágenes) tal y como se despliega.
