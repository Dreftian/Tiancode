# Tiancode Web 1.0.7

Sitio oficial de Tiancode 1.0.7, publicado en https://tiancode.vercel.app/.

- **Novedades 1.0.7:** la tienda Descubrir reúne los plugins, skills y servidores MCP de Claude Code, Codex, los registros MCP y Cline; Conexiones suma cerca de 300 conectores de apps con sus logos reales, y las actualizaciones ya no repiten la bienvenida. La entrada de 1.0.6 pasa a «Anterior».
- **Portada y descargas:** versión y enlaces de descarga actualizados; el texto de portada y la sección de novedades describen esta versión en español e inglés.
- **Caché:** hojas de estilo y scripts con el sufijo `?v=1.0.7-r1` para que el navegador cargue la versión nueva.

Descargas de la aplicación: https://github.com/Dreftian/Tiancode/releases/tag/v1.0.7

El archivo adjunto contiene el sitio estático completo (HTML, CSS, JS e imágenes) tal y como se despliega.
