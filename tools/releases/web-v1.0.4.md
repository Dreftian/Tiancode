# Tiancode Web 1.0.4

Sitio oficial de Tiancode 1.0.4, publicado en https://tiancode.vercel.app/.

- **Novedades 1.0.4:** el agente controla bien el Sandbox, aislado y sin páginas viejas; los sub-agentes se pueden editar; las skills tienen buscador; Ajustes agrupa Servidor y Conexiones; guardar ajustes ya no borra los proveedores ni los servidores MCP. La entrada de 1.0.3 pasa a «Anterior».
- **Portada y descargas:** versión y enlaces de descarga actualizados (~343 MB); el texto de portada y la sección de novedades describen esta versión en español e inglés.
- **Caché:** hojas de estilo y scripts con el sufijo `?v=1.0.4-r1` para que el navegador cargue la versión nueva.

Descargas de la aplicación: https://github.com/Dreftian/Tiancode/releases/tag/v1.0.4

El archivo adjunto contiene el sitio estático completo (HTML, CSS, JS e imágenes) tal y como se despliega.
