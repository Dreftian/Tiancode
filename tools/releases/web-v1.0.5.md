# Tiancode Web 1.0.5

Sitio oficial de Tiancode 1.0.5, publicado en https://tiancode.vercel.app/.

- **Novedades 1.0.5:** Modelos locales ya no pone en riesgo otros archivos y suma los ajustes del motor que faltaban; Skills, MCP y Plugins, Voces, Mascotas y Acerca de se rediseñan; la bandeja del sistema sigue el idioma de la app. La entrada de 1.0.4 pasa a «Anterior».
- **Portada y descargas:** versión y enlaces de descarga actualizados (~343 MB); el texto de portada y la sección de novedades describen esta versión en español e inglés.
- **Caché:** hojas de estilo y scripts con el sufijo `?v=1.0.5-r1` para que el navegador cargue la versión nueva.

Descargas de la aplicación: https://github.com/Dreftian/Tiancode/releases/tag/v1.0.5

El archivo adjunto contiene el sitio estático completo (HTML, CSS, JS e imágenes) tal y como se despliega.
