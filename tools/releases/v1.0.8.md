# Tiancode 1.0.8

Uso de la PC incorpora un operador visual de Windows con el ciclo observar, actuar y verificar, inspirado en las capacidades de escritorio de UI-TARS. El modelo de la conversación recibe la captura del monitor y el contexto necesario para elegir su siguiente acción. Una luz azul en los bordes de todos los monitores muestra cuándo el control está activo.

- **Observación para el modelo:** imágenes adjuntas al resultado de la herramienta, dimensiones y escala del monitor, ventana enfocada, proceso y controles de Windows accesibles mediante UI Automation. Los campos de contraseña se identifican sin leer su valor.
- **Acciones completas de escritorio:** enumerar y activar ventanas, mover el cursor, clic izquierdo, derecho, central y doble, arrastrar con suelta garantizada, escribir texto Unicode, atajos de teclado, desplazamiento vertical y horizontal en un punto, esperar, finalizar y solicitar intervención.
- **Compatibilidad UI-TARS:** interpreta una única `Action:` con `click`, `left_double`, `right_single`, `drag`, `hotkey`, `type`, `scroll`, `wait`, `finished` y `call_user`. Acepta cajas de 0 a 1000, incluidas las del formato `<|box_start|>`. Las predicciones se validan como datos; nunca se ejecutan como Python o shell.
- **Coordenadas precisas:** transforma píxeles de la captura o coordenadas normalizadas al monitor seleccionado, incluso con origen negativo y captura reducida. Una observación se consume tras una acción y se rechaza si caduca, cambia la ventana o cambia el monitor.
- **Control visible y parada:** resplandor azul que deja pasar los clics, barra flotante con Detener y atajo global. La parada interrumpe el arrastre, suelta ratón y modificadores y retira los indicadores. La animación respeta reducir movimiento.
- **Ajustes de Uso de la PC:** guía Observar / Actuar / Verificar, selección de monitor y una petición de ejemplo. Se mantienen los permisos de captura, las autorizaciones por aplicación, el interruptor principal, los ejecutables vetados y la restauración de ventanas.

Para interpretar capturas, selecciona un modelo con visión y herramientas. Las capacidades locales de Windows no añaden operadores remotos, control Android ni soporte nativo en macOS o Linux. La integración aprovecha el modelo y proveedor de la conversación; no instala ni descarga automáticamente los pesos de UI-TARS.

La actualización conserva claves de proveedores, ajustes, sesiones, copias de seguridad y autenticación MCP. Descarga **Tiancode.exe** para instalar o **Tiancode-portable.exe** para la edición portátil. El CLI para Windows, macOS y Linux acompaña esta publicación. Los paquetes locales de Windows no tienen firma de editor; las huellas verifican su integridad.

Referencia: [UI-TARS Desktop de ByteDance](https://github.com/bytedance/UI-TARS-desktop), Apache-2.0. Implementación adaptada a la arquitectura y permisos de Tiancode.
