# Tiancode Web 1.0.0

Sitio oficial de Tiancode 1.0.0, publicado en https://tiancode.vercel.app/. La numeración vuelve a empezar en 1.0.0, igual que la app, el CLI y GitHub.

- **Novedades 1.0.0:** modelos gratuitos de OpenCode (grupo «OpenCode Free» con un interruptor por modelo), asistente de bienvenida de 1200×850 en seis pasos, la mascota en el chat junto a Pensando, Editar o Shell, y una vista previa que ya se cierra sin reabrirse en bucle. La entrada de 1.0.8 pasa a «Anterior» y el historial de 1.0.1–1.0.8 se conserva.
- **Portada y descargas:** versión, textos de portada, metadatos y enlaces de descarga actualizados a 1.0.0 en español e inglés.
- **Caché:** hojas de estilo y scripts con el sufijo `?v=1.0.0-b1007` para que el navegador cargue la versión nueva.

Descargas de la aplicación: https://github.com/Dreftian/Tiancode/releases/tag/v1.0.0

El archivo adjunto contiene el sitio estático completo (HTML, CSS, JS e imágenes) tal y como se despliega.
