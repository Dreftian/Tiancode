# Tiancode 1.0.54

La barra del chat mantiene sus controles en una sola fila, los proveedores desconectados permanecen desactivados y Web App permite elegir una dirección visual que se envía al modelo.

- **Chat adaptable:** más espacio para modelos y Ultracode; las acciones secundarias pasan a Más en paneles estrechos. Build, Plan y Web App siguen siendo las tres opciones principales.
- **Nueva sesión:** su pantalla queda preparada con el compositor, eliminando la espera de otra descarga de módulo en el primer acceso.
- **Proveedores:** una lista del proyecto ya no anula una desconexión global, como ocurría con xKiro. Los avisos de éxito esperan a que el servidor guarde el cambio y los errores permiten reintentar.
- **Especialistas integrados:** la pantalla Sub-Agentes muestra los 14 especialistas incorporados, con búsqueda, estado y alcance global o por proyecto. Se retiran de esa pantalla la tabla y los formularios de agentes de usuario.
- **Dirección visual:** seis estilos originales con vista de ejemplo y una opción para elegir con la IA. La selección se guarda y acompaña al siguiente mensaje de Web App.
- **Respuestas directas:** opción de General para empezar por la acción y presentar pasos breves conservando evidencias, errores y verificaciones.
- **Navegador:** los enlaces pueden abrirse en el navegador integrado, el predeterminado del sistema o Google Chrome. La automatización y la inspección del DOM continúan en el integrado; no se instala Claude in Chrome.
- **Uso de la PC:** opción para restaurar ventanas minimizadas de aplicaciones controladas y autorizadas al terminar. Se mantienen las aplicaciones denegadas, la comprobación del destino de entrada y la parada de emergencia.
- **Cookies:** Hasta salir limpia las particiones del navegador durante un cierre normal; la limpieza al iniciar cubre cierres inesperados.
- **Investigación y diseño:** mejores instrucciones para los especialistas correspondientes, con hipótesis, presupuesto, piloto, evidencias y respeto por la dirección visual elegida.

Rápido sigue disponible con cualquier modelo y conserva el esfuerzo elegido. La aceleración nativa adicional depende del proveedor; no se promete un multiplicador fijo. Ultracode utiliza el mayor esfuerzo compatible y un flujo de planificación, implementación y verificación.

Se mantienen las funciones de dictado y selección de micrófono, mejora del prompt con deshacer, preferencias de transcripción y actividad real en la vista previa de las versiones anteriores. Las actualizaciones conservan claves activas, configuración, sesiones, respaldos y autenticación MCP.

La web y las descargas predeterminadas se actualizan a 1.0.54. Los archivos Windows mantienen los nombres `Tiancode.exe` y `Tiancode-portable.exe`.

Consulta la [evaluación de los diez repositorios e integraciones](https://github.com/Dreftian/Tiancode/blob/dev/tools/releases/integrations-1.0.54.md) y el [informe de validación](https://github.com/Dreftian/Tiancode/blob/dev/tools/releases/audit-1.0.54.md).
