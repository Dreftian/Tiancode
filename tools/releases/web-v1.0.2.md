# Tiancode Web 1.0.2

Sitio oficial de Tiancode 1.0.2, publicado en https://tiancode.vercel.app/.

- **Novedades 1.0.2:** las funciones de opencode v2 en los ajustes, el modo diseño, el emparejamiento por red local y el arranque más rápido, con la entrada de 1.0.1 que faltaba.
- **Portada y descargas:** versión, enlaces de descarga y tamaños actualizados (~343 MB), y el texto de portada describe esta versión en español e inglés.
- **Documentación:** sección de permisos y seguridad enlazada desde el aviso «¿Omitir todos los permisos?» de la app.
- **Caché:** hojas de estilo y scripts con el sufijo `?v=1.0.2-r1` para que el navegador cargue la versión nueva.

Descargas de la aplicación: https://github.com/Dreftian/Tiancode/releases/tag/v1.0.2

El archivo adjunto contiene el sitio estático completo (HTML, CSS, JS e imágenes) tal y como se despliega.
