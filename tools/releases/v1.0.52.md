# Tiancode 1.0.52

Esta versión corrige referencias a modelos locales eliminados, mejora los controles del chat y muestra la actividad real de las herramientas en la vista previa.

- **Modelos locales:** el catálogo reactivo descarta referencias antiguas después del borrado. Un fallo al consultar el inventario ya no se interpreta como una lista vacía. Se conservan los proveedores personalizados y la configuración ajena al modelo eliminado.
- **Subagentes:** catálogo compartido entre los motores con 14 especialistas en ingeniería, programación, diseño, rendimiento, datos, QA, IA, móvil, DevOps, investigación, marketing, ingeniería inversa y seguridad autorizada. Los identificadores antiguos se mantienen como alias para conservar sesiones y configuración.
- **Modo:** Auto, Manual, Aceptar ediciones, Plan y Omitir permisos se aplican a los permisos reales de cada sesión del servidor de escritorio. Las prohibiciones explícitas siguen vigentes.
- **Rápido:** sustituye la promesa de «2x» por la opción nativa de Anthropic cuando el modelo y el servidor son compatibles. Mantiene el esfuerzo elegido; requiere acceso al modo rápido del proveedor y puede tener un coste mayor. La preferencia antigua no activa este coste automáticamente.
- **Ultracode:** flujo de Tiancode para planificar, implementar y verificar trabajos complejos, con `xhigh` o el esfuerzo más alto admitido. No envía un valor de esfuerzo inventado al proveedor.
- **Micrófono y mejora del prompt:** selector de dispositivo visible, grabación mientras se mantiene pulsado, protección frente a arranques/cancelaciones simultáneos y conservación de adjuntos y menciones. El optimizador permite cancelar y deshacer y protege el borrador mientras trabaja.
- **Vista previa y uso de Windows:** seguimiento de herramientas de la sesión activa, estados y destinos visibles, carpeta de proyecto estable, recargas al terminar cambios y registros acotados. Las acciones nativas se serializan y comprueban proceso y ventana antes de enviar entradas.
- **Actualizador:** una descarga fallida queda como error recuperable. La instalación espera al respaldo. La publicación verifica los cuatro archivos antes de hacer visible la nueva versión y no sustituye binarios de versiones ya publicadas.
- **Website:** nuevas funciones y descargas, idioma persistente, enlaces internos corregidos y animación que se pausa fuera de vista. Se retiraron cifras de rendimiento sin mediciones reproducibles.

Se contrastó la última publicación estable de OpenCode, [v1.18.30](https://github.com/anomalyco/opencode/releases/tag/v1.18.30), y se incorporó su selección de prompt para GPT-6 junto con correcciones de selección de modelos. El núcleo V2 sigue en desarrollo: esta versión no promete paridad completa con todo OpenCode. Los modos de permisos y Rápido se deshabilitan explícitamente al usar un servidor V2 que aún no los admite.

Validación: 1.014 pruebas unitarias de interfaz, 41 pruebas de componentes para navegador y 161 pruebas de escritorio aprobadas. También se verificaron especialistas, selección de modelos, transporte HTTP del modo rápido, entradas nativas de Windows y actividad real de la vista previa mediante pruebas específicas. El informe técnico registra el alcance, las mediciones y las comprobaciones manuales pendientes.

Descargas para Windows x64: **Tiancode.exe** (instalador) y **Tiancode-portable.exe**. Las claves, sesiones y configuración existentes se conservan; esta versión no añade migraciones destructivas.
