Descarga

Tiancode 1.0.92 para Windows 10 y 11 (64 bits). Gratis, sin registro. El instalador y la versión portable son el mismo software: elige el que mejor se adapte a tu flujo.

v1.0.92 ~234 MB

Instalador de Windows

Instalación clásica con asistente NSIS. Ideal para uso diario: incluye accesos directos y actualizaciones sencillas.

Tiancode.exe Descargar instalador
v1.0.92 ~234 MB

Versión portable

Sin instalación. Ejecuta Tiancode desde cualquier carpeta o USB; la configuración se guarda junto al ejecutable.

Tiancode-portable.exe Descargar portable

Requisitos del sistema

  • Windows 10 u 11, 64 bits.
  • 4 GB de RAM (8 GB recomendados con modelos locales).
  • 1 GB de espacio libre; los modelos locales y las voces requieren espacio adicional.
  • Internet solo para descargar modelos, conectar GitHub o usar proveedores en la nube.

Verifica la integridad de tu descarga con el hash SHA-256 publicado junto a cada versión.
