Política de privacidad

Tiancode está diseñado con la privacidad por delante: por defecto, tus datos y tu código se procesan en tu propia máquina.

Última actualización: 6 de agosto de 2026

1. Procesamiento local

Tiancode es una aplicación de escritorio. Tus conversaciones, tu código y tu configuración se almacenan y procesan localmente en tu equipo. No mantenemos servidores que reciban tu actividad: la aplicación funciona contra tu propio directorio de datos y no existe una cuenta obligatoria ni una nube a la que se suba tu trabajo.

2. Modelos locales

Si usas modelos locales GGUF, la inferencia se ejecuta íntegramente en tu máquina mediante el backend de llama.cpp. Ni tus mensajes ni los resultados salen de tu equipo: cero envíos de datos. Lo mismo aplica a las voces de lectura (TTS): el modelo de voz kokoro se descarga y ejecuta localmente, y el dictado por micrófono solo se usa mientras mantienes pulsado el botón.

3. Proveedores en la nube

Si decides conectar un proveedor en la nube (OpenAI, Anthropic u otros), tus mensajes se envían a ese proveedor para obtener respuestas, conforme a sus propias políticas de privacidad. La elección es siempre tuya y puedes volver a modelos locales en cualquier momento. Tu clave API se guarda solo en tu equipo, en tu carpeta de datos, y nunca la enviamos a terceros.

4. GitHub

Cuando conectas tu cuenta de GitHub desde Configuración → GitHub, la aplicación actúa como cliente de la API pública de GitHub con tu permiso: lista tus repositorios, clona o crea proyectos y ejecuta commit, push y pull en tu nombre. Las operaciones que realizas son las mismas que harías desde la terminal o la web de GitHub, y puedes revocar el acceso en cualquier momento desde los ajustes de tu cuenta de GitHub. Tiancode no guarda tu token fuera de tu equipo.

5. Telemetría opcional

La aplicación puede enviar estadísticas de uso anónimas (versión, sistema operativo, funciones utilizadas) para ayudarnos a mejorar el producto. La telemetría está desactivada por defecto y solo se activa si tú la habilitas en la configuración. Nunca incluye el contenido de tus conversaciones ni de tu código.

6. No vendemos datos

No vendemos, alquilamos ni compartimos tus datos personales con terceros. Tiancode no tiene un modelo de negocio basado en tus datos: es un producto de software gratuito y de código abierto.

7. Dónde se guarda la información

Toda la información vive en tu equipo:

  • Configuración y claves API: %APPDATA%\Tiancode (instalador) o la carpeta de la app (portable)
  • Modelos locales: %APPDATA%\Tiancode\models dentro del directorio de datos
  • Voces TTS: el modelo de voz se guarda junto a los modelos locales
  • Registros y diagnóstico: logs en la carpeta de datos, solo para resolver incidencias

8. Tus derechos

Como todo se guarda en tu equipo, controlar tus datos es directo: desinstala la aplicación o elimina su carpeta de datos para borrarlo todo. También puedes eliminar conversaciones individuales desde la interfaz, desconectar tu cuenta de GitHub o borrar los modelos descargados desde la pestaña Modelos Locales.

9. Cambios en esta política

Podemos actualizar esta política ocasionalmente. La versión vigente se publica siempre en esta página con su fecha de actualización. Los cambios significativos se anuncian también en las novedades de la aplicación.

10. Contacto

Si tienes preguntas sobre esta política o sobre tus datos, escríbenos a legal@tiancode.dev.
