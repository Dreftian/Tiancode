# Claude Deep Investigation

Systematic exploration and diagnostic methodology for hard-to-reproduce issues.

## 🎯 Methodology
- **Trace Full Call Hierarchy**: Follow execution flow from user input/event triggers down to hardware/network boundaries.
- **State Machine Reconstruction**: Model the actual lifecycle of variables across asynchronous boundaries.
- **Hypothesis-Driven Testing**: Formulate concrete testable hypotheses before making any code modifications.
- **Evidence-Based Proof**: Verify root causes with reproducible log outputs or isolated test fixtures.
