# Claude Performance Optimizer

High-impact performance tuning across web applications, render lifecycles, and local AI agent execution.

## 🎯 Optimization Pillars
1. **Core Web Vitals**:
   - **Largest Contentful Paint (LCP)**: Prioritize critical CSS and preload hero assets.
   - **Interaction to Next Paint (INP)**: Offload heavy computations to web workers and keep event handlers under 16ms.
   - **Cumulative Layout Shift (CLS)**: Set explicit dimensions on images and reserved height for dynamic widgets.
2. **Virtualization**: Render large datasets using windowing/virtual lists to keep DOM node counts minimal.
3. **Memory Health**: Tear down intervals, detach event listeners, and avoid memory retention in closures.
