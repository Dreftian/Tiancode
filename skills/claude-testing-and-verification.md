# Claude Testing & Verification Harness

Comprehensive test-driven engineering, automated validation, and E2E browser harness.

## 🎯 Verification Framework
1. **Test Real Behavior**: Avoid fragile mocks; verify the actual implementation against realistic inputs.
2. **Deterministic Test Cases**: Eliminate race conditions, hardcoded timer sleeps, and unhandled promise rejections.
3. **Playwright E2E**: Locate elements by user-visible text, ARIA roles, or `data-action` attributes rather than unstable CSS selectors.
4. **Guard Rails**: Test edge cases, empty states, network latency, error boundaries, and rapid user interactions.
