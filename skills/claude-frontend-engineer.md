# Claude Frontend Engineer

Specialized frontend engineering skill focused on building high-performance, polished, and accessible user interfaces.

## 🎯 Core Principles
1. **Function-Driven Design**: Identify the core utility before choosing any visual layout. Default to frictionless, intuitive interaction models.
2. **Zero Cliché Tropes**: No over-nested cards, no gradient keyword headlines, no icon-stuffed bento boxes, and no generic purple on dark.
3. **Fluid Responsiveness**: Design interfaces that resize smoothly across breakpoints with adaptive CSS Grid and Flexbox.
4. **Accessibility (a11y)**: Proper ARIA roles, keyboard navigation (`Tab`, `Enter`, `Escape`), focus rings, and high-contrast color ratios.

## 🚀 Execution Workflow
- **Tokens First**: Establish design tokens in CSS variables (`--bg-primary`, `--border-base`, `--text-muted`).
- **Atomic Components**: Build reusable buttons, input fields, selects, switches, and cards with distinct hover, active, disabled, and loading states.
- **Micro-Interactions**: Use CSS transitions with custom cubic-bezier curves for tactile feedback.
- **Verification**: Check layout across viewports and verify with typecheck before submitting.
