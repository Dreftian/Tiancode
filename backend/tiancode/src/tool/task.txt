When NOT to use the Task tool:
- For trivial single-line typo fixes or small 1-line edits in a known single file, execute file tools directly.
- If searching for a single needle identifier like "class Foo" in a known file, use Grep or Read directly.

Usage notes:
1. Launch multiple agents concurrently whenever possible to maximize throughput; send a single message with multiple Task tool calls.
2. Once you have delegated work to an agent, do not duplicate that work yourself. Let the specialist execute its assignment.
3. When the agent is done, it will return its result. Synthesize the findings and explain the completed work to the user.
4. Each agent invocation starts with a fresh context unless you provide `task_id` to resume the same subagent session. Provide clear, detailed requirements in `prompt`.
5. Clearly specify whether the subagent should write/edit files on disk or only investigate.
