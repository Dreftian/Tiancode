1. Instalación

Tiancode 1.0.0 se distribuye en dos formatos para Windows 10 y 11 (64 bits):

  • Instalador NSIS (Tiancode.exe, ~270 MB): instalación clásica con asistente, accesos directos y actualizaciones sencillas.
  • Versión portable (Tiancode-portable.exe, ~270 MB): sin instalación, se ejecuta desde cualquier carpeta o USB.

Requisitos mínimos: Windows 10 u 11 de 64 bits, 4 GB de RAM y 1 GB de espacio libre. Para modelos locales se recomiendan 8 GB de RAM o más. En el primer arranque, un onboarding te muestra el disclaimer de uso responsable de la IA y te deja elegir tema e idioma.

2. Agentes y sub-agentes

Los agentes son asistentes de IA especializados que trabajan en tu proyecto. Puedes tener varios agentes en la misma conversación, delegar tareas a sub-agentes y asignar a cada uno un rol (senior-dev, reviewer, arquitecto…).

$ tiancode --agent senior-dev

Cada agente mantiene su propio contexto y puede ejecutar comandos en la terminal integrada para verificar su trabajo antes de proponer cambios. Los sub-agentes se crean desde Configuración → Sub-Agentes: eliges el modo (primary o subagente), el modelo, uno de los 8 colores, las herramientas permitidas (con permisos finos entre lectura y escritura) y un system prompt propio. La barra de título tiene toggles para mostrar u ocultar la terminal y el panel de archivos.

3. Skills

Tiancode incluye 52+ skills de ingeniería de software listas para usar: entrevistas de requisitos, TDD, code review, auditoría de seguridad, optimización de rendimiento, CI/CD, refactorización, depuración asistida, frontend-design, grill-me, writing-plans, planning-and-task-breakdown, using-git-worktrees y más.

La pestaña Skills las lista con paginación, muestra sus detalles en markdown al costado y permite activar o desactivar cada skill con un toggle. También puedes crear las tuyas propias añadiendo archivos a la carpeta de skills: cada skill define el flujo de trabajo que sigue el agente.

4. Modelos locales

Desde la pestaña Modelos Locales puedes buscar y descargar modelos GGUF directamente desde HuggingFace, al estilo LM Studio. El flujo completo:

  1. Abre Configuración → Modelos Locales y explora el catálogo, por ejemplo llama-3.1-8b-instruct.
  2. Filtra con el buscador y elige una cuantización: Q2_K, Q3_K_L, Q4_K_M, Q6_K, Q8_0, la familia IQ* o F16. La app muestra el tamaño exacto de cada archivo.
  3. Comprueba el indicador de compatibilidad (verde, azul o rojo) y el panel de Información del sistema, que detecta automáticamente tu RAM, disco libre, GPU y CPU.
  4. Descarga el archivo: verás una barra de progreso y la descarga se reanuda si la conexión se corta. El espacio libre en disco se verifica antes de empezar.
  5. Selecciona el modelo local como proveedor activo y empieza a conversar sin conexión.
%APPDATA%\Tiancode\models\llama-3.1-8b-instruct.Q4_K_M.gguf

La ejecución usa el backend de llama.cpp: funciona en CPU y aprovecha las GPUs NVIDIA o AMD cuando están disponibles.

5. GitHub

Configuración → GitHub conecta tu cuenta sin salir de la app. Después de iniciar sesión una vez:

  • Lista tus repositorios y el estado del remoto directamente en la app.
  • Clona repositorios existentes o crea otros nuevos desde una plantilla.
  • Haz commit, push y pull desde la conversación, sin navegador.
  • Desconecta la cuenta cuando quieras; el token se guarda solo en tu equipo.

6. Servidores MCP

La pestaña MCP Servers conecta herramientas externas mediante el Model Context Protocol. Incluye 8 presets locales listos para usar: filesystem, fetch, memory, sequential-thinking, time, playwright, context7 y git. El catálogo Discover añade 15 servidores populares:

  • Locales: android-emulator, node-repl, ios-simulator, chrome-devtools, playwright, context7, aikido (con clave) y airwallex (con clave).
  • Remotos: canva, circle, appwrite, apollo, graphos-tools, atlan y awsknowledge.

Cada servidor muestra su estado en vivo, agrupado en Conectado, Errores, Desactivado y Desconocido, junto con el número de herramientas que expone. Los servidores remotos se conectan por URL y algunos requieren una clave API que se añade después de crearlos.

7. Plugins

La pestaña Plugins instala apps desde npm o plugins locales con un clic. El catálogo incluye @biomejs/biome, @playwright/mcp, @octokit/rest, @slack/web-api, @notionhq/client, @sentry/cli, agent-notify y @chime-io/plugin-claude, además de plugins locales como env-guard, commit-helper, notify-idle y shell-env.

8. Voces TTS

Configuración → Voces descarga el modelo de voz kokoro (solo escritorio) y te deja elegir la voz con una vista previa. Las voces femeninas aparecen primero, con idiomas como español, inglés, francés, hindi, italiano, japonés, portugués y chino. Con la voz seleccionada, la app puede leer las respuestas en voz alta, y el botón de micrófono del campo de mensaje te permite dictar en lugar de escribir.

9. Bandeja del sistema

En Configuración → General, activa «Minimizar a bandeja»: al minimizar o cerrar, Tiancode se queda en la bandeja del sistema y vuelves a tu conversación con un clic en el icono, sin perder el contexto.

10. Configuración

El diálogo de configuración (1240 px) usa un sidebar compacto con 12 pestañas: General, Atajos, Servidores, Proveedores, Modelos, Modelos Locales, GitHub, Voces, Plugins, Skills, Sub-Agentes y MCP Servers. En la barra de título de la ventana, junto a los botones de minimizar, hay toggles para mostrar u ocultar el terminal y el panel de archivos.

11. Comandos

La CLI de Tiancode expone comandos útiles desde cualquier terminal:

tiancode                     # Abre la aplicación
tiancode --agent senior-dev  # Inicia un agente concreto
tiancode --portable          # Fuerza el modo portable
tiancode --models            # Abre la gestión de modelos locales
tiancode --version           # Muestra la versión instalada

12. Solución de problemas

  • El modelo local va lento: elige una cuantización menor (Q4 en lugar de Q8) o un modelo más pequeño.
  • La descarga de modelos falla: comprueba la conexión y el espacio libre en la carpeta de modelos.
  • No conecta con el proveedor: revisa la clave API en Configuración → Proveedores.
  • GitHub no sincroniza: revisa la conexión en Configuración → GitHub y, si hace falta, vuelve a conectar la cuenta.
  • Un servidor MCP aparece en «Errores»: revisa el comando o la URL del servidor y su requisito de clave API.
  • Las voces no se escuchan: comprueba que el modelo de voz está descargado en Configuración → Voces.
  • La app no arranca en modo portable: asegúrate de tener permisos de escritura en la carpeta.
  • ¿Sigue el problema? Abre una incidencia adjuntando los logs de la carpeta de datos.
